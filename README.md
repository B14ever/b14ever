## How I work

- **Architecture first**: Clean Architecture, SOLID, and modular, feature-based structure so codebases stay easy to change
- **Offline-first by default** when users work in the field, with local persistence and reliable sync
- **Performance-minded**: profiling state management and rendering rather than guessing
- **Integration-heavy**: National ID verification, banking services, Firebase, and third-party REST APIs
